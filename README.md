# SISCAN

Documentação de recuperação e protótipo didático do SISCAN.

- `docs/recovery/`: decisões, fontes, análises e limites documentados.
- `siscan-prototype/`: aplicação local em Python e interface web; consulte seu README para execução.

O protótipo utiliza dados sintéticos. Bancos de execução, sessões, senhas, materiais originais CMO/DB3K e arquivos temporários não pertencem ao repositório.

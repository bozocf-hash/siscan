# 02 — Visão geral do SISCAN

## Finalidade e limites

**DECIDIDO (Missão 01):** ferramenta de simulação, análise e apoio ao ensino, inicialmente para instrutores e alunos em planejamento e análise de cenários acadêmicos. ATLANTICADOR fornece base cartográfica e capacidades existentes de visualização/manipulação geográfica, sujeitas a auditoria. O SISCAN não é sistema de recomendação operacional para emprego de armas.

## Usuários previstos

| Perfil | Papel conceitual |
|---|---|
| Administrador | Administração geral; permissões específicas pendentes |
| Instrutor | Prepara cenário, recursos, libera submissões e avalia |
| Aluno Azul / Aluno Vermelho | Organiza forças, registra e justifica decisões |
| Avaliador | Avalia exercício; escopo e relação com instrutor pendentes |
| Observador | Acompanha conforme autorização a definir |

**DECIDIDO:** submissões de alunos permanecem privadas entre pares até liberação do instrutor.

## Módulos concebidos

| Sigla | Módulo | Escopo conceitual |
|---|---|---|
| GEO | Geografia | Cartografia, validação espacial |
| SYM | Simbologia | Integração Calunga |
| AST | Cadastro de meios | Modelos, configurações, sensores/equipamentos |
| SCN | Cenários | Criação, versões, gestão |
| FOR | Forças | Organização e composição |
| DID | Didático | Exercícios, atividades, submissões |
| SIM | Simulação | Abstração e adjudicação humana |
| ANA | Análise | Relatórios/resultados |
| NAV | Navegação | Posição e tempo simulado |
| LOG | Logística | Combustível, autonomia, manutenção e apoio |
| PRC | Poder Relativo de Combate | Indicadores didáticos configuráveis |
| HIS | Histórico | Eventos, alterações e auditoria |
| MPNL | Planejamento de Necessidades Logísticas | Materiais, sobressalentes, estoques, orçamento |

Todos são **DECIDIDOS como concepção**, não como componentes comprovadamente existentes.

## Visão da primeira entrega

**PLANEJADO:** instrutor cria cenário didático e disponibiliza meios; aluno organiza composição e justifica decisões; instrutor avalia; sistema consolida relatório. Fluxos, dados, autorização, critérios de avaliação e critérios de aceite continuam pendentes. Ver requisitos em [05](05_REQUISITOS_FUNCIONAIS.md).

# 49 — Registro consolidado das decisões APR-01 a APR-20

## Autoridade e escopo

Este documento incorpora o arquivo `Documento_Consolidado_Decisoes_SISCAN_APR-01_a_APR-20.docx`, fornecido pelo responsável do projeto em 08/11/2026. Ele é a referência de governança para o resultado da pauta APR-01 a APR-20 e complementa os documentos 35–48. “Aprovada” significa decisão conceitual registrada, não autorização para implementar.

O registro consolida decisões integrais e parciais, ajustes, recomendações não aprovadas e pendências. A conclusão das 20 matérias não constitui especificação completa nem autoriza programação, alterações de código, banco, configuração, integrações ou protótipo. Não inicia a próxima fase.
